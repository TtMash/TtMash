### 🧩 Deep Learning Puzzle Solver
> *Computer Vision · Image Segmentation · Combinatorial Optimisation*

- 🎯 Built a deep learning pipeline that **generated segmentation masks for 500 unlabelled puzzle pieces** using a model trained on 500 existing masks
- 🔧 Designed a **full puzzle reconstruction system** that assembled all 1,000 pieces and produced an adjacency matrix encoding spatial piece relationships
- 📐 Applied **semantic segmentation, convolutional feature extraction, and optimisation algorithms** to tackle large-scale combinatorial reconstruction

---

### 🌍 Seismic Reconstruction Model Comparison *(Honours Research)*
> *Deep Learning · Scientific Computing · 3D Data Restoration*

- 🔬 Evaluated **CNN, ResNet with Attention, and Vision Transformer (ViT)** architectures on real-world Orange Basin 3D seismic data
- 📊 Designed a **synthetic noise augmentation pipeline** to simulate realistic seismic degradation scenarios
- 📈 Assessed reconstruction fidelity across **5 metrics: PSNR · MSE · RMSE · SSIM · MS-SSIM**
- 🛢️ Findings carry direct implications for **subsurface imaging and energy sector** data restoration workflows

---

### 📊 Unsupervised Learning & Dimensionality Reduction Suite
> *Representation Learning · Clustering · Latent Space Analysis*

- 🧬 Benchmarked **5 dimensionality reduction methods**: Autoencoder, VAE, AE+SOM, AE+t-SNE, AE+UMAP
- 🔵 Applied **k-Means clustering** to each learned 2D embedding and conducted comparative cluster quality analysis
- 🎨 Produced rich **latent space visualisations** to surface structural patterns in high-dimensional data
